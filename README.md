# 学生会信息管理系统

应用经济学院学生会日常事务管理平台，纯前端实现（HTML + CSS + 原生 JavaScript），可直接部署在 GitHub Pages，无需服务器与数据库。

## 功能模块

| 模块 | 能力 |
| --- | --- |
| 工作台 | 在任成员、部门数、报名人次、例会出勤率四项指标，近期公告与活动报名进展、物资借出提醒 |
| 成员与部门 | 成员名册增删改查、按部门筛选与关键词搜索、职务与在任状态管理、部门人数分布统计 |
| 活动与报名 | 发布/编辑/删除活动，设置名额与承办部门，勾选式报名名单，超名额自动拦截，报名进度可视化 |
| 通知公告 | 公告发布、编辑、删除、置顶，工作台同步展示 |
| 考勤签到 | 新建例会、成员逐个签到/取消，实时统计应到/实到/缺席/出勤率，历次出勤横向对比 |
| 物资借还 | 物资台账、借出登记（借用部门、借出与应还日期）、一键归还入库、临期提醒 |

## 技术说明

- **零依赖**：不引入任何前端框架、CDN 或第三方脚本，离线可用。
- **数据存储**：使用浏览器 `localStorage`（键名 `su_ms_v1`），数据仅保存在本机浏览器，不上传任何服务器。
- **数据导出**：侧边栏「导出数据」可将全部数据导出为 JSON 备份；「恢复演示数据」一键还原初始样例。
- **响应式**：桌面端侧边栏布局，窄屏自动收缩为单列，表格可横向滚动。

## 目录结构

```
.
├── index.html                 # 唯一入口页，含侧边栏与六个视图容器
├── assets/
│   ├── style.css              # 蓝白主题样式与响应式布局
│   └── app.js                 # 数据层（localStorage）、各模块渲染与交互
├── .github/workflows/pages.yml# 推送到 main 分支时自动发布到 GitHub Pages
└── README.md
```

## 本地运行

直接双击 `index.html` 即可，或起一个本地静态服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署到 GitHub Pages

1. 仓库 Settings → Pages → Source 选择 **GitHub Actions**（工作流首次运行会自动启用 Pages）。
2. 推送到 `main` 分支后，Actions 中的 `Deploy to GitHub Pages` 会自动构建并发布。
3. 发布完成后访问 `https://<用户名>.github.io/<仓库名>/`。

## 数据安全提示

演示数据中的手机号已做脱敏处理（如 `138****6621`）。正式使用时请勿在公开仓库中提交真实学号、手机号等个人敏感信息；如需多人协同与真实权限控制，应改为接入后端数据库并把数据存于服务端。
