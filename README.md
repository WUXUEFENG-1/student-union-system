# 云南工业信息职业学院应用经济系学生会管理系统

应用经济系学生会办公与审批平台。纯前端实现（HTML + CSS + 原生 JavaScript），数据通过 Supabase REST 云端实时同步，浏览器 `localStorage` 作为离线兜底，可直接部署到静态托管（Cloudflare Pages / GitHub Pages）。支持导出 Excel / Word / PDF / CSV。

## 角色与权限

系统共五类角色，登录后菜单按角色动态生成，越权操作不会出现在界面上。

| 角色 | 账号 | 密码 | 权限说明 |
| --- | --- | --- | --- |
| 系统管理员 | `admin` | `123456` | 拥有全部后台权限；系统监测、操作日志、账号管理、人事任免、部门终审、活动终审、考核、通知与请假审批 |
| 责任教师（指导教师） | `teacher` | `123456` | 与管理员同等的全部后台权限；活动终审、考核复核、查看人事与台账 |
| 主席团（主席 / 副主席） | 由成员台账生成 | — | 活动一级审核、请假审批、任免成员、管理部门、考核部长/副部长、复核部内成员考核、发布通知 / 信息收集 / 活动报名 |
| 部长团（部长 / 副部长 / 干事） | 由成员台账生成 | — | 维护本部门信息与成员、申请 / 修改 / 撤销部门活动、考核部内成员并提交复核、审批部内请假、发布通知 / 信息收集 / 活动报名、考勤签到与物资借还 |
| 普通学生 | 由成员台账生成 | — | 查看部门信息与通知、在「我的申请」提交各类申请、请假、报名活动、填写信息收集表、修改个人资料与密码 |

> 成员台账默认空表，真实成员与登录账号由管理员通过人事导入、账号导入或信息收集建立；导入时可按部门 / 职务自动判定账号角色。

## 部门设置

标准部门：**主席团、秘书部、宣传部、实践部、权益服务部**（部门管理可申请新增，管理员终审）。

- 部门信息仅同步本部门成员，人数由人员信息表实时统计，无需手工填写。
- 成员数据支持一键导入：每行一名成员，按「姓名,性别,族别,政治面貌,所在班级,联系电话,部门,学号,账号,初始密码,职务」排列，逗号或制表符分隔（可从 Excel 复制粘贴），也可上传 Excel（.xlsx）或 CSV/TXT；账号与初始密码留空则只建成员档案。

## 业务模块与流程

| 模块 | 说明 |
| --- | --- |
| 工作台 | 按角色汇总待办审批（含待审批申请）、在任成员、进行中收集、可报名活动与最新通知 |
| 系统监测 | 各业务表记录条数、存储占用、账号角色分布、最近操作日志（管理员 / 责任教师） |
| 操作日志 | 登录、审批、任免、导入、导出、删除等关键操作自动留痕，可按操作人检索并导出（管理员 / 责任教师） |
| 活动审批 | **三级串联**：部门提交申请 → 主席团审核 → 责任教师（或管理员）终审；任一节点驳回即终止；承办部门可修改、撤销 |
| 人事管理 | 成员信息表、一键导入、新增成员、职务调整、罢免、单条删除（二次确认，同时移除登录账号，历史记录归档可查）与批量删除 |
| 账号管理 | 批量导入登录账号与初始密码，单个新增、重置密码、移除账号、角色分配与导出（管理员 / 责任教师） |
| 部门管理 | 部门信息、成员构成与人数同步；主席团提交新增 / 罢免申请，管理员终审 |
| 考核管理 | 百分制四维录入：出勤（满分 30）、工作任务（满分 40）、思想纪律（满分 15）、群众评价（满分 15），总分封顶 100；按总分给出 **优秀 / 良好 / 合格 / 不合格** 等级 |
| 通知公告 | 部长团及以上发布 / 撤回通知；可选生效范围（全员 / 指定部门 / 部长团 / 主席团）与可选附件；附件可导出留档 |
| 请假管理 | 按层级送审；申请人可撤回待审申请；申请人本人或管理员可删除请假记录（删除后不计入出勤考核，日志保留）；支持可选附件（如病假证明） |
| 我的申请 | 八类在线申请：**部门调整申请**（默认入口）、部门调动申请、退会申请、意见反馈与诉求、述职申请（部长团 / 主席团可见）、换届竞选报名、任职证明申请、志愿服务认定申请；逐级审批，通过后自动落库（调动 / 调整更新部门岗位与账号角色，退会置为已退会，志愿时长累加，任职证明生成编号） |
| 信息收集 | 发布收集任务（自定义收集项、截止日期）；成员与学生在线填写、修改、查看；明细可导出 |
| 活动报名 | 发布活动可设人数上限；在线报名 / 取消；报名名单展示学号与状态，管理员 / 发布人可删除单条报名记录（删除后立即释放名额、不计入本次出勤） |
| 考勤签到 | 部长团附加：例会签到、出勤率统计，仅统计本部门在任成员 |
| 物资借还 | 部长团附加：物资台账、借出登记与归还入库 |
| 个人信息 | 资料维护、修改密码（新密码至少 6 位）、查看当前角色权限说明 |

## 技术说明

- **零前端依赖**：不引入框架与第三方脚本；.xlsx 解析为内置轻量实现（ZIP + XML）。
- **数据存储**：Supabase 表 `state`（单行 jsonb，云端为准）；`localStorage` 键 `su_ms_v4` 作离线兜底，登录态存于 `sessionStorage`。云端有数据时以云端覆盖本机，避免已删除的部门 / 成员 / 通知被本机残留数据「复活」。
- **导出格式**：Excel（.xls）、Word（.doc）、PDF（浏览器打印另存）与 CSV（带 UTF-8 BOM，Excel 直接打开不乱码）。
- **响应式**：桌面端侧边栏布局，窄屏收起为抽屉式菜单，表格横向滚动。

## 目录结构

```
.
├── index.html                  # 登录页 + 主界面壳（内联 SVG favicon）
├── assets/
│   ├── style.css               # 蓝白主题、校徽 data URI、登录页与响应式布局
│   ├── data.js                 # 角色、种子账号、五部门与各业务表结构、操作日志
│   ├── app.js                  # 角色权限、菜单生成、考核等级、多格式导出、日志/监测/工作台
│   ├── app2.js                  # 活动三级审批、人事、部门、考核、通知、请假、我的申请、账号管理
│   ├── app3.js                  # 信息收集、活动报名、考勤、物资、个人信息
│   ├── import-sync.js           # 导入覆盖层：按部门/职务自动落库与角色保留
│   ├── cloud-sync.js            # Supabase 云端为准同步与本地兜底
│   ├── xlsx-reader.js            # 轻量 .xlsx 解析（ZIP + XML，无第三方依赖）
│   └── logo.png / logo-small.png
└── README.md
```

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

- **Cloudflare Pages / GitHub Pages**：静态托管仓库根目录，入口页引用 `assets/` 下的 CSS 与 JS；云端地址在 `cloud-sync.js` 中配置。
- **EdgeOne Pages 等静态托管**：直接托管仓库根目录即可。

## 数据安全提示

演示账号密码仅用于联调。正式上线需接入后端鉴权与行级权限；当前云端表为班级内部使用的开放读写口径，不应存放未经脱敏的学生敏感信息。
