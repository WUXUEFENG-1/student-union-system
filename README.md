# 云南工业信息职业学院应用经济系学生会管理系统

应用经济系学生会办公与审批平台。纯前端实现（HTML + CSS + 原生 JavaScript），数据存储于浏览器 `localStorage`，无需服务器与数据库，可直接部署到静态托管（GitHub Pages / EdgeOne Pages）。支持导出 Excel / Word / PDF / CSV。

## 角色与权限

系统共四类角色，登录后菜单按角色动态生成，越权操作不会出现在界面上。

| 角色 | 演示账号 | 密码 | 权限说明 |
| --- | --- | --- | --- |
| 管理员 | `admin` | `123456` | 拥有全部权限；额外具备系统监测（数据规模、存储占用、运行状态）与操作日志（查看、检索、导出、清空）能力；可批量导入登录账号与初始密码、重置/移除账号；人事任免、部门终审、活动与请假审批、考核主席团成员 |
| 主席团（主席 / 副主席） | `president`、`vice` | `123456` | 拥有全部业务权限：审批活动与请假、任免成员、管理部门、考核部长/副部长、复核部内成员考核、发布通知 / 信息收集 / 活动报名、提交本人请假 |
| 部长团（部长 / 副部长） | `minister`、`vminister` | `123456` | 维护本部门信息与成员、申请 / 修改 / 撤销部门活动、考核部内成员并提交复核、审批部内成员与普通学生的请假和入会申请、发布通知 / 信息收集 / 活动报名、考勤签到与物资借还 |
| 普通学生 | `student` | `123456` | 查看部门信息与通知、提交加入部门申请、提交请假、报名活动、填写并提交信息收集表、修改个人资料与密码 |

> 审批权限：日常请假、入会申请由所申请部门的**部长或副部长**审批；主席团、管理员可在全部审批事项中处理。系统不设指导教师与干事角色。

## 部门设置

仅保留五个部门：**主席团、秘书部、宣传部、实践部、权益服务部**。

- 部门信息仅同步本部门成员（含部长、副部长、成员），人数由人员信息表实时统计，无需手工填写。
- 成员数据支持**一键导入**：每行一名成员，按「姓名,性别,族别,政治面貌,所在班级,联系电话,部门,学号,账号,初始密码」排列，逗号或制表符分隔（可直接从 Excel 复制粘贴），也可上传 Excel（.xlsx）或 CSV/TXT 文件；账号与初始密码留空则只建成员档案；部门须属于上述五个标准部门。

## 业务模块与流程

| 模块 | 说明 |
| --- | --- |
| 工作台 | 按角色汇总待办审批、在任成员、进行中收集、可报名活动与最新通知 |
| 系统监测 | 各业务表记录条数、本地存储占用、账号角色分布、最近操作日志（仅管理员） |
| 操作日志 | 登录、审批、任免、导入、导出等关键操作自动留痕，保留最近 300 条，可按操作人检索并导出 Excel / Word / PDF / CSV（仅管理员） |
| 活动审批 | 部长团申请活动（协同部门及人数、总人数、时间地点、内容）→ 部长/副部长或主席团审批；承办部门可修改、撤销 |
| 人事管理 | 成员信息表、一键导入、新增成员、职务调整、罢免与人事异动记录；成员信息可导出 Excel / Word / PDF / CSV |
| 账号管理 | 管理员批量导入登录账号与初始密码（格式：姓名,性别,族别,政治面貌,所在班级,联系电话,部门,学号,账号,初始密码,职务,角色），支持粘贴文本或上传 Excel（.xlsx）/CSV/TXT，单个新增、重置密码、移除账号与导出账号；成员登录后可自行修改密码，用户名保持不变（仅管理员可见） |
| 部门管理 | 部门信息、成员构成与人数同步；主席团提交新增 / 罢免申请，管理员终审 |
| 考核管理 | 管理员考核主席团 → 主席团考核部长/副部长 → 部长/副部长考核部内成员（提交主席团复核） |
| 通知公告 | 部长团及以上发布 / 撤回通知 |
| 请假管理 | 普通学生、成员请假送部长/副部长；部长请假送主席团；主席团请假送管理员；申请人可撤销待审申请 |
| 加入申请 | 普通学生提交入会申请 → 所申请部门部长/副部长审核，通过即入册为成员 |
| 信息收集 | 部长、副部长或主席、副主席发布收集任务（可自定义收集项、截止日期）；成员与普通学生在线填写、修改、查看；明细可导出 Excel / Word / PDF / CSV（CSV 带 BOM，Excel 直接打开不乱码） |
| 活动报名 | 部长、副部长或主席、副主席发布活动（名额限制）；成员与普通学生在线报名 / 取消报名；报名名单可查看并导出 Excel / Word / PDF / CSV |
| 考勤签到 | 部长团附加：例会签到、出勤率统计，仅统计本部门在任成员 |
| 物资借还 | 部长团附加：物资台账、借出登记与归还入库 |
| 个人信息 | 资料维护、修改密码（新密码至少 6 位）、查看当前角色权限说明 |

## 技术说明

- **零依赖**：不引入前端框架与第三方脚本，离线可用。
- **数据存储**：`localStorage`（键 `su_ms_v4`），登录态存于 `sessionStorage`，数据不出本机；更换浏览器或清除站点数据后恢复为种子演示数据。
- **导出格式**：支持 Excel（.xls）、Word（.doc）、PDF（浏览器打印另存）与 CSV（带 UTF-8 BOM），中文在 Excel / Word 中正常显示。
- **响应式**：桌面端侧边栏布局，窄屏收起为抽屉式菜单，表格横向滚动。

```

```

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

- **GitHub Pages**：仓库 Settings → Pages → Source 选择 GitHub Actions；推送到 `main` 后由工作流自动发布。Actions 默认令牌无权自动创建 Pages 站点，首次需在仓库设置中手动开启一次。
- **EdgeOne Pages 等静态托管**：直接托管仓库根目录即可；单 HTML 托管场景下，入口页通过 CDN 地址引用 `assets/` 下的 CSS 与 JS。

## 数据安全提示

演示数据中的手机号为脱敏值，账号密码仅为演示用途。正式上线需接入后端与真实鉴权，不应把学生真实信息提交到公开仓库。
