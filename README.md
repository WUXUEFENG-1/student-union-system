# 学生会信息管理系统

应用经济学院学生会办公与审批平台，按《需求文档》的角色分工实现五类角色、七张业务表的完整审批链。纯前端实现（HTML + CSS + 原生 JavaScript），可部署在 GitHub Pages，无需服务器与数据库。

## 角色与权限

| 角色 | 演示账号 | 可执行操作 |
| --- | --- | --- |
| 指导老师 | `teacher` / `123456` | 提升或罢免成员职务、审核部门（新增/编辑/罢免）、活动终审与一票否决、主席团考核、发布/撤回通知、审核主席团请假 |
| 主席团 | `presidium` / `123456` | 罢免成员职务、编辑部门信息并提交新增/罢免请求给老师、活动审批、部长考核、发布/撤回通知、提交/撤销本人请假并审核部长请假 |
| 部长团 | `minister` / `123456` | 罢免本部门干事、维护本部门信息、申请/修改/撤销部门活动、干事考核并提交审核、请假申请与干事请假审核、审核学生入会申请、发布/撤回通知 |
| 干事 | `staff` / `123456` | 修改个人信息、查看通知、提交请假申请 |
| 普通学生 | `student` / `123456` | 查看部门信息、提交加入部门申请 |

登录后菜单按角色动态生成，越权操作不会出现在界面上。

## 业务表与流程

| 表 | 对应模块 | 流程 |
| --- | --- | --- |
| ① 部门信息表 | 部门管理 / 部门信息 | 主席团编辑信息、提交新增/罢免申请 → 指导老师终审生效；部长团维护本部门；学生只读 |
| ② 部门申请表 | 部门管理 | 主席团提交 → 指导老师审核（新增/罢免/编辑） |
| ③ 活动信息表 | 活动审批 / 活动管理 | 部长团申请（协同部门及人数、总人数、时间地点、内容）→ 主席团或老师任一方同意即通过 → 老师可一票否决；承办部门可修改/撤销 |
| ④ 人员信息表 | 人事管理 | 老师可提升/罢免任意成员；主席团可罢免非主席团成员；部长可罢免本部门干事；全部留痕 |
| ⑤ 加入申请 | 加入申请 / 我的申请 | 学生提交 → 所申请部门部长审核 → 通过即入册为干事 |
| ⑦ 请假表 | 请假管理 | 按层级送审：主席团→老师、部长→主席团、干事→部长团；申请人可撤销待审申请 |
| ⑧ 考核表 | 考核管理 | 老师考核主席团、主席团考核部长、部长考核干事（提交后由主席团复核） |
| 附加 | 考勤签到 / 物资借还 | 文档外的部长团日常工具，仅部长团可见 |

## 技术说明

- **零依赖**：不引入任何前端框架、CDN 或第三方脚本，离线可用。
- **数据存储**：`localStorage`（键 `su_ms_v2`），登录态存于 `sessionStorage`，数据不出本机。
- **登录**：登录页内置五个演示账号，点击即可自动填充；退出登录后回到登录页。
- **响应式**：桌面端侧边栏布局，窄屏收起为抽屉式菜单，表格横向滚动。

```
├── assets/
│   ├── style.css               # 蓝白主题、登录页与响应式布局

├── .github/workflows/pages.yml # 推送到 main 自动发布到 GitHub Pages
└── README.md
```

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署到 GitHub Pages

1. 仓库 Settings → Pages → Source 选择 **GitHub Actions**。
2. 推送到 `main` 后，Actions 中 `Deploy to GitHub Pages` 自动发布。
3. 访问 `https://<用户名>.github.io/<仓库名>/`。

> 说明：GitHub Actions 默认令牌无权自动创建 Pages 站点，因此首次需在仓库设置中手动开启一次。

## 数据安全提示

演示数据中的手机号为脱敏值，账号密码仅为演示用途。正式上线需接入后端与真实鉴权，不应把学生真实信息提交到公开仓库。
