# 应用经济系学生会管理系统 · 微信小程序端

本目录是与网页版**并列新增**的小程序源码端，网页版 `assets/` 保持原样、未做改动。两端共用同一套 Supabase 云端数据（`state` 表 `id=1` 的 `data` jsonb 行），登录账号与网页版一致。

## 本地运行

1. 用**微信开发者工具**导入本 `mp/` 目录。
2. 开发阶段：详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」（工程配置 `urlCheck:false` 已默认开启）。
3. 登录账号与网页端一致，例如：
   - 管理员 `admin / yyadmin`
   - 主席 `yyjjx01 / yyadmin`
   - 副主席 `yyjjx02 / 123456`
   - 各部门部长 / 副部长 / 成员见云端 `accounts`

## 数据与权限口径

- 读：启动时拉取云端整份数据；云端不可达则回退本地缓存。
- 写：审批通过 / 驳回 / 删除 / 操作日志等变更整份回写云端，并同步本地缓存。
- 审批权限、部长/副部长申请链、退回与通知规则与网页端 `app4.js` / `app6.js` 最终版一致；权限判定按 `applyStages` 实际节点岗位匹配，不跨级代审。

## 已实现能力

- 账号登录、工作台统计、角色菜单
- 九类在线申请表单提交（部门调整/调动、退会、意见反馈、述职、换届竞选、任职证明、志愿服务认定、活动公假证明），字段与网页端一致
- 请假申请提交、通过/驳回/撤回/删除，按角色分流审核人
- 审批通过前手写签字（canvas）+ 联系电话 + 审批意见，签字与轨迹留存云端，详情页可查看签字缩略图
- 图片附件选择并转 base64 存入同一云端记录，详情页可预览大图
- 待我审批：通过流转下一节点 / 终审通过 / 驳回填原因，节点权限隔离，消息通知
- 例会考勤签到：新建例会、本部门在任成员到/未到切换、出勤率统计
- 物资台账：新增物资、借出登记、归还入库、删除
- 活动报名：报名 / 取消报名、名额上限校验
- 各台账列表与通用详情（字段 + 申请内容 + 附件 + 签字 + 审批轨迹时间线）
- 我的申请 CSV 导出（写入本地文件后调起微信分享/打开）
- 个人信息、退出登录、操作日志

## 平台限制说明

微信小程序运行环境与浏览器不同，以下网页端能力受平台约束，未在小程序内复刻：

- **Word / PDF / Excel 文档导出**：小程序无浏览器 Blob / atob / docx 渲染环境，台账导出首版提供 CSV；证明类签字文档仍走网页端导出。
- **XLSX 模板解析导入**：小程序端未内置 xlsx 解析库，批量账号/成员导入仍在网页端完成。
- **附件下载**：图片附件可在详情页预览；文件类附件的离线下载/另存需在网页端处理。
- 复杂排版证明、手写签字打印版式以网页端导出为准。
